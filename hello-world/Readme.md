# Overview

As a software engineer, I wanted to verify that my development environment is fully set up and ready for productive work. Creating a simple Hello World program is the classic first step when learning a new language or confirming that tools, version control, and publishing workflows are functioning correctly.

This software is a small Node.js console application that prints a friendly greeting along with basic identifying information. It confirms that JavaScript can be written, executed, and shared successfully from my machine.

My purpose in creating this software was to practice the complete professional workflow I will use throughout the semester: writing clean code, documenting it with a proper README, recording a short demonstration video, and publishing everything to a public GitHub repository.

[Software Demo Video](https://www.youtube.com/watch?v=1r-WpvIf2zc)

# Development Environment

- Editor: Visual Studio Code
- Runtime: Node.js
- Version Control: Git and GitHub
- Operating System: Windows / macOS / Linux

Programming language: JavaScript (executed with Node.js)

No external libraries were required for this starter project.
